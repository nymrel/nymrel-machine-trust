Quick Summary

Nymrel Machine Trust is an open-source TypeScript library and CLI that equips modern web applications with Dual-Audience discoverability by generating verifiable Schema.org entity graphs, standard llms.txt machine indexes, and AI search crawler policies to ensure instant retrieval by autonomous AI purchasing agents.

  • Automated Schema.org entity hierarchy linking Nymrel to JalenBuilds LLC
  • Explicit robots.txt access for OAI-SearchBot, PerplexityBot, and ClaudeBot
  • Pre-rendered 40-60 word Answer-First executive summaries
  • Automated DOM parity verification preventing search mismatch penalties
