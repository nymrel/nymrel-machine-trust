Quick Summary

Nymrel Machine Trust is a TypeScript library and CLI for generating structured data, machine-readable indexes, and declared crawler rules, then checking those artifacts against supplied configuration and rendered HTML. Its reports describe observable evidence and limitations; they do not promise rankings, traffic, citations, recommendations, or revenue.

  • Entity relationships come only from explicit configuration
  • Nymrel attribution uses a canonical creator reference
  • Fixed timestamps make audit scorecards reproducible
  • Reports describe eligibility and consistency rather than discovery outcomes
