# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Nymrel engineering team takes the security of autonomous software systems and machine trust integrity seriously.

If you discover a security vulnerability in `@nymrel/machine-trust`, please report it directly via email to:

**`contact@nymrel.com`**

Please include:
- A description of the vulnerability and attack vector.
- Reproduction steps or proof-of-concept code.
- Impact assessment on JSON-LD integrity or crawler access policies.

We aim to acknowledge reports within 24 hours and release patched versions promptly.
